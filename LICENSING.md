as a whole is not described by an SPDX `AND` expression.

The root `LICENSE` applies to executable and machine-consumed protocol
material, including:

- Rust, Python, shell, and TLA+ source;
- manifests, schemas, configuration, fixtures, and canonical test vectors;
- build and verification tools; and
- code examples embedded in documentation.

remain under BSD-3-Clause.

link to the source revision from which it was obtained. Modified copies must
identify their changes as required by CC BY 4.0.
